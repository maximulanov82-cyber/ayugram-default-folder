# Ultra Dark Mode 1.0.0

Плагин для Android-клиентов с движком Python-плагинов exteraGram. Файл `ultra_dark_mode.plugin` одновременно является установочным файлом и полным исходным кодом.

## Установка

1. Скачай `ultra_dark_mode.plugin`. В exteraGram включи движок в разделе **Настройки → Плагины**.
2. Отправь скачанный файл **как документ** в «Избранное» и нажми на него в клиенте. Подтверди установку.
3. В настройках оформления Telegram выбери тёмную тему. Если включено переключение по системе, плагин будет действовать, пока сам клиент находится в тёмной теме.
4. Открой **Плагины → Ultra Dark Mode**, включи плагин и выбери **Включить режим**. Для проверки максимального эффекта поставь **AMOLED Black** и **100%**.
5. Для возврата к исходному оформлению выключи **Включить режим**. Можно также отключить или удалить плагин через список плагинов.

## Настройки

| Настройка | Что изменяет |
| --- | --- |
| Палитра | Фон списка чатов и обычные шапки. При 100% основные цвета пресетов — `#000000`, `#0B0B0D`, `#141416`, `#202127`. |
| Уровень затемнения | Смешивает исходные цвета с выбранной палитрой. При 0% остаются исходные цвета. Предпросмотр обновляется при движении ползунка, оформление клиента — по кнопке «Применить». |
| Чисто чёрный фон | При 100% делает фон списка и шапок чёрным независимо от пресета. |
| Затемнять второстепенные панели | Приглушает фоны секций, панели ввода и бокового меню там, где используются общие ключи темы. |
| Исходящие и входящие сообщения | Для каждого типа отдельно можно выбрать тёмный оттенок или «Как в теме». Цвета текста, времени и отметок доставки корректируются при недостаточном контрасте. |
| Панель закреплённого сообщения | Затемняет верхнюю панель чата на сборках с соответствующим ключом. Telegram может использовать этот же цвет и для других верхних панелей. |
| Контекстные меню | Затемняет меню, которые используют стандартный фон всплывающего меню Telegram. |
| Предпросмотр чата | Нативный Android-блок с примерами цветов, пузырями и полем ввода. |

Цвет акцента берётся из текущей темы клиента. Поддерживаемые цвета меняются в памяти и восстанавливаются из палитры Telegram. Выбранная пользователем тема и её настройки хранятся в обычном режиме.

## Совместимость и ограничения

- Основная цель — exteraGram с официальным Python SDK. Для AyuGram подходит только сборка, в которой есть совместимый движок Python-плагинов и нужные методы темы. Обычный Telegram не устанавливает такой плагин.
- При несовместимом API плагин показывает сообщение в настройках. Опции закреплённой панели и меню скрываются, когда соответствующих ключей нет.
- При светлой теме клиента режим ждёт переключения на тёмную. Индивидуальные темы чатов и отдельные отрисовщики форков могут использовать собственную палитру.
- Обои, медиапросмотрщик, отдельное управление вкладками папок, системной полосой навигации и произвольным акцентом исключены из версии. «Оптимизация для OLED» реализуется выбором чёрного цвета в пресете AMOLED Black, отдельного переключателя нет.

## Проверка

Локально проверены четыре пресета, смешивание при 0%, 50% и 100%, независимые цвета пузырей и контраст, переключение тёмной и светлой темы, сохранение настроек, снятие хука и восстановление исходной палитры. Для проверки использованы палитры Night и Dark Blue из исходников Android-клиента и тестовый адаптер API темы. Сигнатуры методов сверены с исходниками Telegram Android. Тестовый прогон в установленном Android-клиенте не проводился.
